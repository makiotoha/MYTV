# MYTV 直播源配置与自动更新

本项目为自动抓取与整理的 IPTV 直播源仓库。

---

## 📌 声明与致谢

- **源项目出处**：本项目基于上游开源项目改造与扩展，特此对原作者表示感谢。
- **项目定位**：本项目仅用于个人学习、技术研究与直播源格式整理，不存储、不制作任何音视频内容。

---

## 🔗 直播源订阅链接

你可以直接在 **MYTV**、**TVBox** 或其他支持 IPTV 订阅的播放器中添加以下订阅链接：

| 格式类型 | 订阅链接 (GitHub Pages 加速) |
| :--- | :--- |
| **M3U 格式** | `https://makiotoha.github.io/MYTV/best_sorted.m3u` |
| **M3U8 格式** | `https://makiotoha.github.io/MYTV/best_sorted.m3u8` |

> 💡 **提示**：后台工作流每 4 小时会自动更新并筛选一次最新可用的直播源。
